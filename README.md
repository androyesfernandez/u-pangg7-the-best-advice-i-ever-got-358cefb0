A program that writes one sentence about the best advice ever received into `/output/entry.txt`. The sentence is a father's advice about being on time — advice that only made sense twenty years later, when the apology it was really about finally landed.

## Run

Requires Node 22 or later. No dependencies, no network.

```sh
node main.ts
```

This writes `/output/entry.txt` with exactly one line of text (119 characters, no trailing newline).

## The line

> My dad said, "If you cannot be on time, be early," and twenty years on I finally heard what he meant: stop apologizing.
